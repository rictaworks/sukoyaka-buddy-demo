# フォントライセンス表記

`NotoSansJP-VF.ttf` は Google Fonts が配布する **Noto Sans JP**（可変フォント）です。

- ライセンス: SIL Open Font License, Version 1.1
- 配布元: https://fonts.google.com/noto/specimen/Noto+Sans+JP
- 入手経路: Windows 11 に標準搭載のフォントとして同梱されていたものを転用（`C:\Windows\Fonts\NotoSansJP-VF.ttf`）

SIL OFL 1.1 はフォントの再配布・組み込み利用を許諾するライセンスであり、本リポジトリへの同梱・ビルド成果物への埋め込みは許諾範囲内。
