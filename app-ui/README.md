# app-ui

デザインモック配置場所。本プロジェクトは事前のデザイン指定（Figma等のモック）を受け取っておらず、現時点ではモック未提供です。

- 事前にデザイン指定が届いたら、このディレクトリにモックを配置する
- `app-ui/` は参照専用（デザイン確認用）で、実装のEdit scopeには含めない
- モックが提供された場合、実装時はここのモックを `Assets/Scripts/View/` に再現したうえで実際のロジック（`Assets/Scripts/Core/`・`Assets/Scripts/Persistence/`）に接続する（[CLAUDE.md](../CLAUDE.md) 参照）
- 本プロジェクトの画面は基本図形（円・矩形・リング）とuGUIの標準コンポーネントのみで構成する方針（requirements.md 1.3節）のため、モックが最後まで提供されない可能性がある
